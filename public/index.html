LOCAL BY DEFAULT, EXPLICIT BY DESIGN

Know where your data goes.

Stays on this machine

Uploaded video, extracted speech, transcripts, thumbnails (none generated), caption edits, renders, live buffers and the SQLite job database. Speech uses an installed faster-whisper model in offline mode. Models are never downloaded during transcription.

No analytics, external fonts, automatic uploads, folder scanning or public tunnel.

Leaves only when requested

URL import/live capture contacts the source platform (IP and source URL visible there). Configured remote AI receives transcript text, not video, audio or images, after per-run approval. Publishing sends the selected video, text and credentials to the selected platform.

No remote transcription or frame-analysis feature exists in this build. A provider's own retention policy applies to data you send.

Optional moment-selection model

OpenAI-compatible chat-completions endpoint. Local Ollama/LM Studio can keep text local; remote HTTPS requires your consent. No endpoint is preconfigured.

Local runtime

See the repository README for model installation, token scopes, start/stop, retention and current integration limits. Data is retained until you remove it; uninstalling the app does not erase the data directory.
